🎯 OBJECTIF
-----------
Comparer votre méthode RL de génération de contrefactuels avec la baseline
ForecastCF sur iTransformer + ETTh1, sans modifier le code original de
ForecastCF.

✨ POINTS CLÉS
--------------
✅ Code ForecastCF original NON MODIFIÉ
✅ Adaptation PyTorch dans des fichiers séparés
✅ Scripts d'exécution prêts à l'emploi
✅ Outils de comparaison et visualisation
✅ Documentation complète en français

🚀 DÉMARRAGE RAPIDE
-------------------
1. Vérifier: python baselines/check_setup.py
2. Installer: pip install -r baselines/requirements_baseline.txt
3. Lancer:   bash baselines/run_comparison.sh

📊 RÉSULTATS GÉNÉRÉS
--------------------
Après exécution, vous obtiendrez:

├── ForecastCF/results/
│   └── forecastcf_etth1_itransformer.csv    Résultats ForecastCF

└── comparison_plots/
    ├── comparison_barplot.png               Barres avec erreurs
    ├── comparison_boxplot.png               Distributions
    └── comparison_radar.png                 Vue d'ensemble

-------------------

- Utiliser d'autres datasets (Weather, Traffic, Tourism)
- Ajuster le nombre d'échantillons de test

📝 NOTES IMPORTANTES
--------------------
1. Le code TensorFlow original de ForecastCF reste intact
2. L'adaptation PyTorch est dans des fichiers séparés
3. Les paramètres sont alignés pour une comparaison équitable
4. Les mêmes métriques sont utilisées pour les deux méthodes
5. Les seeds sont identiques (1, 9, 30, 33, 39)

🏆 AVANTAGES ATTENDUS DE VOTRE MÉTHODE RL
------------------------------------------
Votre méthode devrait surpasser ForecastCF sur:
✓ Validité (optimisation RL dans l'espace latent)
✓ Proximité (masque temporel pour perturbations localisées)
✓ Compacité (perturbations plus sparses)
✓ Vitesse (forward pass unique vs optimisation itérative)
✓ Généralisation (politique globale vs instance-specific)
